# Dokumentation

Zwei Bereiche. Die Anleitungen führen eine Maschine vom leeren Ubuntu bis zu einem eigenen Modul. Die Regeln legen fest, wie das Repository aufgebaut bleibt.

| Bereich | Aufgabe |
|---|---|
| [tutorials/](tutorials/README.md) | Maschine, Start, Umgebung, Make, eigene Module |
| [rules/](rules/README.md) | Ordner, Tests, Stack, API, Betrieb |

## Lesepfad

1. [Ubuntu-VM, Docker und erster Start](tutorials/01-ubuntu-vm.md)
2. [Umgebung, weitere Datenbanken, Make](tutorials/02-umgebung-und-befehle.md)
3. [Eigene Implementierung](tutorials/03-eigene-implementierung.md)
4. [Zertifikate in Entwicklung und Produktion](tutorials/04-zertifikate.md)

Wer das Repository schon starten kann, beginnt bei der Umgebung. Wer ein Modul baut, liest danach die [Ordnerstruktur](rules/ordnerstruktur.md) und die [API-Regeln](rules/api.md).
